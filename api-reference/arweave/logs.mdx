<Note>
  This endpoint requires authentication via an **API key**. Include your key in
  the `x-api-key` header. Get your API key from
  [In•Process Settings](https://inprocess.world/manage/api-keys).
</Note>

## Overview

After uploading files to Arweave (via the [Turbo SDK](/api-reference/arweave/upload)), call this endpoint to log the results. Each submitted URI is verified on-chain before being recorded. URIs that cannot be verified are returned in the `failed` array.

## Example Request

```bash
curl -X POST https://api.inprocess.world/api/arweave/logs \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '[
    {
      "arweave_uri": "ar://TV4yYVYJ7mwsDZ19h_YNQBtRbLVIr_WITsrBnHxxW30",
      "winc_cost": "1234567",
      "file_size_bytes": 204800,
      "content_type": "image/jpeg"
    }
  ]'
```

## Example Response

```json
{
  "logged": ["ar://TV4yYVYJ7mwsDZ19h_YNQBtRbLVIr_WITsrBnHxxW30"],
  "failed": []
}
```

## Request Body

An array (minimum 1 item) of upload objects:

| Field             | Type    | Required | Description                                        |
| ----------------- | ------- | -------- | -------------------------------------------------- |
| `arweave_uri`     | string  | Yes      | Arweave URI of the uploaded file (`ar://` prefix). |
| `winc_cost`       | string  | Yes      | Upload cost in winston credits.                    |
| `file_size_bytes` | integer | Yes      | File size in bytes.                                |
| `content_type`    | string  | Yes      | MIME type of the file (e.g. `image/jpeg`).         |

## Response Fields

| Field    | Type       | Description                                                         |
| -------- | ---------- | ------------------------------------------------------------------- |
| `logged` | `string[]` | URIs that were verified on Arweave and successfully recorded.       |
| `failed` | `string[]` | URIs that failed on-chain verification and were **not** logged.     |
