---
title: Get Arweave Upload Logs
description: Retrieve paginated Arweave upload logs for the authenticated artist.
openapi: GET /arweave/logs
---

<Note>                                                                                                  
  This endpoint requires authentication. You can use either a bearer token in the `Authorization` header or an API key in the `x-api-key` header.                                     
</Note>

- Artist can get their own logs.
- Admin can retrieve all logs across artists.
