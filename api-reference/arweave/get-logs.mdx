---
title: Get Arweave Upload Logs
description: Retrieve paginated Arweave upload logs for the authenticated artist.
openapi: GET /arweave/logs
---

<Note>
  This endpoint requires authentication. You can use either a bearer token in the
  `Authorization` header or an API key in the `x-api-key` header.
</Note>

## Overview

Returns Arweave upload log records ordered by `created_at` (newest first).

- Artist can get their own logs.
- Admin can retrieve all logs across artists.

## Query Parameters

| Parameter | Type    | Required | Default | Description                                  |
| --------- | ------- | -------- | ------- | -------------------------------------------- |
| `limit`   | integer | No       | `20`    | Number of records per page (`1` to `100`).  |
| `page`    | integer | No       | `1`     | 1-based page number.                         |

## Example Request

```bash
curl "https://api.inprocess.world/api/arweave/logs?limit=20&page=1" \
  -H "x-api-key: YOUR_API_KEY"
```
